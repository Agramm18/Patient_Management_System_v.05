# Patient Management System V5.01

Patient Management System V5.01 is a Java-based console application that simulates core workflows of a modern hospital management system.

The project is being developed as a learning and portfolio project to gain practical experience in software architecture, database design, authentication systems, security concepts, and enterprise application development.

## Current Scope

The system currently focuses on:

* Authentication and authorization
* User and account management
* Database design, integration, and management
* Department, role, permission, and job management
* Bootstrap, configuration, and authentication workflows
* Login and registration processes

## Planned Features

* Patient management
* Appointment scheduling
* Hospital administration
* Audit logging
* Reporting and analytics
* JavaFX user interface
* REST API integration
* Docker and Kubernetes deployment

## Technologies

* Java 21
* Maven
* MySQL
* JDBC
* BCrypt
* Git
* GitHub
